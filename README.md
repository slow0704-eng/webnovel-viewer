## 빌드

원고는 상위 폴더 `projects/<작품>/chapters/chNN.md`에 있습니다.

```
cd tools && python build.py   # → index.html
```

`main`에 push하면 GitHub Pages가 1–2분 뒤 반영합니다.

모든 작품의 조직·사건·인물은 허구이며 실존 인물·기관과 무관합니다.
